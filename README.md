## 🎯 Proje Açıklaması

Trabzon Airlines, modern web teknolojileri kullanılarak geliştirilmiş kapsamlı bir havayolu rezervasyon sistemidir. Proje, kullanıcıların uçuş arama, rezervasyon yapma, hesap yönetimi ve çeşitli havayolu hizmetlerine erişim sağlayabileceği responsive bir web uygulamasıdır.

### ✨ Özellikler

- 🔍 **Uçuş Arama ve Rezervasyon**
  - Gelişmiş arama filtreleri
  - Gerçek zamanlı fiyat karşılaştırması
  - Esnek tarih seçenekleri

- 🌍 **Çok Dilli Destek** ✅
  - Türkçe ve İngilizce dil seçenekleri
  - Dinamik dil değiştirme
  - Sayfa geçişlerinde dil korunması

- 📱 **Responsive Tasarım** ✅
  - Mobil uyumlu arayüz
  - Mobil alt navigasyon çubuğu
  - Tablet ve desktop optimizasyonu
  - Modern UI/UX tasarımı

- 🖼️ **Optimized Media** ✅
  - Yerel resim dosyaları
  - SVG placeholder'lar
  - Hızlı yükleme performansı

- 🧭 **Gelişmiş Navigasyon** ✅
  - Logo tıklaması ile ana sayfa
  - Ortalanmış footer tasarımı
  - Responsive sidebar menü

## 🚀 Kurulum ve Çalıştırma

### Gereksinimler
- Modern web tarayıcısı (Chrome, Firefox, Safari, Edge)
- Yerel web sunucusu (opsiyonel)

### Kurulum Adımları

1. **Projeyi klonlayın:**
   ```bash
   git clone https://github.com/OnurAkyuz61/COM5005-WebProgramming-Project.git
   cd COM5005-WebProgramming-Project
   ```

2. **Yerel sunucu başlatın (opsiyonel):**
   ```bash
   # Python ile
   python -m http.server 3000
   
   # Node.js ile
   npx serve .
   
   # VS Code Live Server eklentisi ile
   # Sağ tık > "Open with Live Server"
   ```

3. **Tarayıcıda açın:**
   ```
   http://localhost:3000
   ```
